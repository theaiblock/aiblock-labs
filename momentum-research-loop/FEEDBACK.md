# User feedback

Agents read this after `MANDATE.md` and before choosing an experiment. Newer active feedback overrides older suggestions, but not the mandate unless the user edits the mandate too.

## Active feedback

- Do not spend every iteration tuning a single lookback or apparent winner.
- If three consecutive experiments use the same strategy family, the next experiment must use a materially different family or regime filter.
- Use at least two years of data.
